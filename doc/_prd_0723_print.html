1. 背景与目标

1.1 背景

当前后台已具备登录注册、会员管理、产品上架等基础能力。为支撑运营与商家侧业务，需要在不引入完整服务端的前提下（本期仍允许本地 mock / localStorage），补齐运营素材、商家商品体系与管理员个人资料三类能力。

1.2 本期目标

  1. Banner 图管理 + 本地上传
  2. 商家管理模块（商家存在性 + SKU）
  3. 当前登录用户 Profile 修改

1.3 非目标（本期不做）

  • 真实后端 API / 数据库落库
  • 对象存储（OSS/S3）云端上传
  • 前台 C 端商城展示页完整实现（仅后台管理）
  • 复杂权限体系（多角色审批流）

2. 范围总览

章节改动点优先级
3Banner 图管理与本地上传P0
4商家管理与 SKUP0
5登录用户 Profile 修改P0

侧边导航建议新增：Banner 管理、商家管理、个人资料（或顶栏入口）。

3. 改动点一：Banner 图管理与本地上传

3.1 需求说明

后台增加 Banner 管理模块，运营可维护首页/活动位 Banner 列表，并支持从本地选择图片上传（浏览器本地读取，本期可存 Base64 或 ObjectURL + localStorage 元数据）。

3.2 功能清单

编号功能说明
3.2.1Banner 列表展示标题、预览图、排序、启用状态、更新时间
3.2.2新建 Banner填写标题、跳转链接（可选）、排序、启用开关
3.2.3本地上传图片选择本地图片文件；校验类型与大小后预览
3.2.4编辑 Banner修改文案、链接、排序、图片、启用状态
3.2.5删除 Banner二次确认后删除
3.2.6启用/停用快速切换是否展示

3.3 字段定义

字段类型必填说明
idstring系统生成唯一标识
titlestring是Banner 标题，≤ 40 字
imageDatastring是本地上传后的图片数据
linkUrlstring否点击跳转地址
sortnumber是排序值，越小越靠前
enabledboolean是是否启用
updatedAtnumber系统更新时间戳

3.4 本地上传规则

  • 支持格式：PNG / JPEG / WebP
  • 单文件大小：≤ 2MB
  • 上传后立即本地预览；刷新后尽量可恢复

3.5 验收标准

  1. 能新建 Banner 并看到本地上传图片预览
  2. 能编辑、删除、启用/停用
  3. 非法类型或超大小时有明确错误提示
  4. 刷新后数据不丢失（配额允许范围内）

4. 改动点二：商家管理模块（商家 + SKU）

4.1 需求说明

新增「商家管理」模块，用于管理商家主体是否存在/可用，并维护其下的 SKU 信息。

4.2 商家管理功能

编号功能说明
4.2.1商家列表名称、联系人、状态、SKU 数量、更新时间
4.2.2新建商家创建商家主体
4.2.3编辑商家修改基础信息与营业状态
4.2.4停用/启用商家停用后其 SKU 不可再上架销售
4.2.5删除商家级联删除 SKU + 二次确认

4.3 商家字段

字段类型必填说明
idstring系统商家 ID
namestring是商家名称
contactstring否联系人
phonestring否联系电话
statusenum是active / inactive
remarkstring否备注

4.4 SKU 管理功能

编号功能说明
4.4.1SKU 列表按商家过滤
4.4.2新建 SKU绑定当前商家
4.4.3编辑 SKU修改价格、库存、名称等
4.4.4上架/下架 SKU控制可售状态
4.4.5删除 SKU二次确认

4.5 SKU 字段

字段类型必填说明
idstring系统SKU ID
merchantIdstring是所属商家
namestring是SKU 名称
skuCodestring是同商家内唯一
pricenumber是≥ 0
stocknumber是≥ 0 整数
statusenum是on / off

4.6 业务规则

  1. 商家 inactive 时，其下 SKU 不可新建为上架
  2. 同一商家下 skuCode 不可重复
  3. 删除商家采用级联删除 + 二次确认

4.7 验收标准

  1. 可创建商家并看到列表
  2. 可为商家维护 SKU（增删改、上下架）
  3. 重复 SKU 编码有校验提示
  4. 停用商家后上架被拦截或自动下架

5. 改动点三：当前登录用户 Profile 修改

5.1 需求说明

后台增加 Profile 能力，当前登录管理员可修改自己的展示信息与登录密码。

5.2 功能清单

编号功能说明
5.2.1查看 Profile用户名、角色、展示名、邮箱/手机
5.2.2修改基础资料昵称、邮箱、手机号
5.2.3修改密码校验原密码后设置新密码
5.2.4保存反馈成功/失败提示；顶栏展示名同步

5.3 字段定义

字段可改说明
username否登录名
displayName是昵称
email是邮箱格式校验
phone是可选
password是（经原密码）≥ 6 位

5.4 交互与校验

  1. 改密需原密码 + 新密码 + 确认
  2. 原密码错误 / 两次不一致分别提示
  3. 仅允许修改当前登录账号

5.5 验收标准

  1. 可打开 Profile 并看到当前账号
  2. 修改昵称后刷新保留且顶栏同步
  3. 正确/错误原密码行为符合预期
  4. 未登录访问跳转登录页
